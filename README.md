# 공가(空家) 🏚️

> **전부 비었어야 할 단지에, 302호에만 불이 켜져 있다.**

철거를 일주일 앞둔 1980년대식 복도식 아파트를 무대로 한 **1인칭 공포 어드벤처 게임**입니다.
무기 없이, 문을 닫고 숨으며 소리로 사냥하는 괴물 「집주인」에게서 살아남아야 합니다.

「게임 물리와 상호작용」 텀 프로젝트

---

## 어떤 게임인가요?

주인공은 철거 전 빈집 확인 업무를 맡은 용역 직원입니다.
눈 내리는 겨울밤, 아무도 없어야 할 단지를 돌다가 302호의 불빛을 발견합니다.
남겨진 일기장, 사진, 카세트테이프를 조사할수록 30년 전 이 단지에서 한 아이가 사라진 사건이 드러납니다.

```
1층  관리사무소   손전등과 열쇠 꾸러미를 챙긴다. 위층에서 무언가 끌리는 소리.
2층  201호        방화 셔터가 올라가고, 센서등이 하나씩 켜지며 복도 끝에 무언가가 서 있다.
3층  301~303호    302호의 불빛을 따라간다. 그리고 처음으로 쫓긴다.
지하 보일러실     30년 동안 차려진 제사상. 모든 진실이 있는 곳.
```

## 괴물: 「집주인」

- 옛날 집 지킴이 신이 뒤틀린 존재. 뜯겨 나간 **벽지, 장판, 녹슨 문패**가 사람 모양으로 뭉쳐 기어 다닌다.
- **눈이 없다. 소리로만 사냥한다.** 뛰는 발소리, 떨어뜨린 물건, 셔터 소리가 그를 부른다.
- 닫힌 문은 잠시 두드리다 부수고 들어온다. 장롱에 숨으면 찾지 못한다.

## 원칙

- **무기가 없습니다.** 숨기(장롱)와 시간 벌기(문 닫기)로만 살아남습니다.
- **손으로 직접 조작합니다.** 문, 서랍, 차단기 레버는 마우스로 잡고 끌어서 엽니다 (Rigidbody/Joint 기반 물리).
- **소리가 곧 위험입니다.** 플레이어가 내는 모든 큰 소리는 괴물에게 들립니다. 반대로 물건을 던져 괴물을 유인할 수도 있습니다.
- **보여주기보다 들려줍니다.** 공포는 소리만 → 실루엣 → 추격 → 최종 추격 순서로 단계적으로 커집니다.

## 기능 로드맵

| 단계 | 기능 | 상태 |
|---|---|---|
| MVP | 1인칭 이동, 손전등 | ⬜ |
| MVP | 문/서랍 마우스 드래그 조작 | ⬜ |
| MVP | 맵 4개 구역 (1층·2층·3층·지하) | ⬜ |
| MVP | 단서 (일기장, 사진, 카세트테이프) | ⬜ |
| MVP | 2층 연출 (방화 셔터, 센서등, 실루엣) | ⬜ |
| MVP | 괴물 기본 추격, 엔딩 1개 | ⬜ |
| 목표 | 소리 감지 AI, 장롱 숨기, 문 부수기, 물건 던져 유인, 체크포인트 | ⬜ |
| 여유 | 엔딩 2개, 괴물 외형 디테일, 사운드 강화 | ⬜ |

## 구조

```
입력(Input System) → Player ─ 이동 / 시점 / 손전등
                        └ Interactor ─ Raycast → IInteractable (문, 서랍, 레버, 단서, 장롱)
                                                     │
                        큰 소리 ── NoiseSystem.Emit(위치, 크기) ──→ Monster AI (NavMesh)
                                                                   순찰 → 의심 → 추격 → 수색
```

```
Assets/
  MyScripts/      # 직접 작성한 스크립트 (Core, Player, Interaction, Monster, Noise, Story, UI)
  OtherScripts/   # 외부에서 가져와 수정한 스크립트 (출처 표기)
  Prefabs/  Materials/  Audio/  Textures/
  Scenes/         # SampleScene = 메인 씬
  Credits.txt     # 무료 리소스 출처
```

## 기술 스택

- 엔진: **Unity 6000.5.1f1** (버전 고정)
- 렌더링: URP 17.5.0
- 입력: Input System 1.19.0
- 괴물 AI: AI Navigation 2.0.13 (NavMesh)
- 협업: Git + GitHub, Git LFS

## 실행 방법

1. Unity Hub에 **Unity 6000.5.1f1**을 설치합니다. (다른 버전으로 열거나 업그레이드하지 마세요)
2. Git LFS를 켠 뒤 저장소를 받습니다.
   ```bash
   git lfs install
   git clone https://github.com/ParkTaeMin2663/gongga.git
   ```
   > 경로에 한글이 없고 OneDrive 밖인 곳에 받으세요. (예: `C:\Unity\gongga`)
3. Unity Hub → `Add` → `Add project from disk` → 받은 폴더 선택
4. `Assets/Scenes/SampleScene`을 열고 ▶ Play

> 처음 열 때는 `Library` 폴더를 새로 만드느라 몇 분 걸립니다.
